# 衡迹 · 称量测次复核台

衡迹把称量过程的离散采样整理为可复核、可交付的数据产品。归集两份乱序到达的采集包后，工作台按加载计划对齐证据，从首尾空盘示值估计零点漂移，分别计算示值偏差、回程差、重复性、偏载和零漂，并保留判定使用的输入。

当工位在升程后卸荷清零、由接班人继续回程与偏载时，测次可声明「中途清零」。工作台把升程段与回程段各自按本段两次空盘修正，清零跳变不当作零漂，零漂分段落判后取最不利。复核员可以在后段尚未归集时确认并交接升程段的两条示值检查；交接只是本段证据，不等于整场签出，签出时会核对当前升程读数与有效交接一致。

## 启动

需要 Python 3.11+、SQLite 3.35+（启用 JSON 函数）和支持原生 ES modules、`dialog`、Canvas 的现代浏览器。无需 pip、npm、外部数据库或联网。

```sh
python3 -B -m weightrace --demo
```

在浏览器打开 `http://127.0.0.1:8837/`。默认把工作记录保存在当前目录的 `weightrace.sqlite3`；用 `--db /path/to/work.sqlite3` 更换数据库，或用 `--port 0` 自动选择本机端口。不加 `--demo` 可从空库开始，也可在界面载入样例。

## 一次完整的复核

1. 打开「椴木台 · 03」。样例的 10 步完整，初始整体判定为「临界」。在「原始采集」可以查看包编号和摘要。
2. 点击「签出交付件」取得 v1。导入 `examples/linden-late.json` 后，左偏载会出现两条有效候选，当前复核阻塞，v1 保持不变。
3. 回到「测次复核」，打开偏载左位的「证据」，剔除 `LINDEN-08` 并填写事由，保留原始行。此时判定变为「超限」，仍可签出 v2。
4. 在「交付历史」对账 v1 与 v2，检查左位证据和分项变化。可分别复算、下载或撤回。撤回只登记状态与事由，不改写已下载的证据。

样例还包含桤木台「中途清零」测次 `ALDER-0920`：升程段与回程段各有一次空盘，清零处示值跳变远大于零漂。「升程交接」可确认首空盘、升低、升高与清零前空盘四条读数；导入另一包的迟到清零前空盘候选后，交接显示失效并阻止签出，剔除迟到候选后仍需重新确认才能签出。

自建测次时先在「砝码凭据」登记修订，再选择日期、低高档组合、分度与各分项上限；升程后需卸荷清零的测次勾选「中途清零」。采集包是 `{"id":"包编号","rows":[...]}` 形式的 UTF-8 JSON；每行必须包含 `id`、`step`、`observed_at` 和整数 `indicated_mg`，具体约束见 `PROJECT_SPEC.md`。

## 本机验证

```sh
python3 -B -m tools.smoke
```

演练会在临时 SQLite 文件与自动分配的本机端口验证十一条真实 HTTP 工作流（含中途清零的升程交接），不改动工作数据库。可用 `--through <工作流ID>` 仅运行到某一步。

分段修正与交接规则的独立检查在 `tests/`：

```sh
python3 -B -m unittest discover -s tests
```

本应用是单机合成数据复核工具；没有登录或远程部署前提，不控制设备，也不提供现实检定或电子签名服务。
